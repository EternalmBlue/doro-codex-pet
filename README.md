# Doro Codex Pet

## 中文

一个自定义 Codex pet 包，形象是粉色短发、白色团子身体的小型像素风桌宠。

### 文件

- `pet.json` - Codex pet 清单文件。
- `spritesheet.webp` - 1536 x 1872 动画图集。
- `qa/contact-sheet.png` - 按行检查的 QA 预览图。
- `qa/videos/*.mp4` - 每个状态的动画预览视频。

### 状态

图集包含标准 Codex pet 动画行：

- idle
- running-right
- running-left
- waving
- jumping
- failed
- waiting
- running
- review

A custom Codex pet package with a compact pink-haired white dumpling sprite.

- `spritesheet.webp` - 1536 x 1872 animated pet atlas.
- `qa/contact-sheet.png` - row-by-row QA contact sheet.
