# Doro Codex Pet

A custom Codex pet package with a compact pink-haired white dumpling sprite.

## Files

- `pet.json` - Codex pet manifest.
- `spritesheet.webp` - 1536 x 1872 animated pet atlas.
- `qa/contact-sheet.png` - row-by-row QA contact sheet.
- `qa/videos/*.mp4` - animation previews for each state.

## States

The spritesheet includes the standard Codex pet rows:

- idle
- running-right
- running-left
- waving
- jumping
- failed
- waiting
- running
- review
